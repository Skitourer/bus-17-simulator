# Contributing

- Open an issue first: clear title, what you expect, how to check it.
- Work on a short branch named `<type>/<short-description>` (e.g. `feat/cabin-view`).
- Commits and PR titles follow [Conventional Commits](https://www.conventionalcommits.org/)
  (`feat`, `fix`, `docs`, `refactor`, `test`, `perf`, `ci`, `build`, `chore`).
- One PR = one topic. It references its issue (`Closes #12`) and says why, what was
  checked, and what a human must test in the browser.
- Code, comments and commits in English. Docs in English with a French mirror
  (`page.md` / `page.fr.md`).
- Never commit secrets, `.env` files, personal data or downloaded caches.

Coding agents: see [AGENTS.md](AGENTS.md).
